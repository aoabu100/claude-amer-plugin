# Writing style

- Lead with the point. First sentence answers the reader's question.
- Short paragraphs (2–4 sentences). Lists only when items are parallel.
- Plain words over jargon. Active voice. No filler openers.
- One idea per section; headings only if the piece is over ~300 words.
- End with a clear next step or ask.
- Edit this file to add your own voice rules (words to avoid, sign-off, tone).
